# Driftwise

A playable 3D browser prototype for **Driftwise**, a calm tactical meditation runner about flow, movement styles, and the strange comedy of trying to stay centered while dodging traffic cones, emails, ramps, and pony opinions.

## Play Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://127.0.0.1:5173/
```

## Prototype Includes

- Main menu, body selection, settings, archive, pause, soft reset, and run summary
- One 3D level: **The Station of Almost Arriving**
- Three playable bodies: Walker, Wheelchair, and Pony
- Lane movement, jumping or body-specific actions, flow meter, insight fragments, soft collisions, and contextual humour
- Flow Run and Zen Drift modes
- Accessibility settings for reduced motion, high contrast, larger text, speed, sound, humour, and no-fail play

## Controls

- `A` / left arrow: move left
- `D` / right arrow: move right
- `W` / up arrow / space: jump or upward body action
- `S` / down arrow: duck, brake, or downward body action
- Shift: focus ability
- Mobile: swipe to move/action, hold for focus
